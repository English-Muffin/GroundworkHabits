# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, keep feedback about the work, and leave out harassment,
insults and personal attacks in issues, pull requests and anywhere else the project lives.

## Reporting

Report unacceptable behaviour privately to the maintainer through a
[private security advisory](https://github.com/English-Muffin/GroundworkHabits/security/advisories/new)
(it is the one private channel this repository has). Reports are kept confidential. The maintainer may
remove comments, close threads or block accounts that break this code.
